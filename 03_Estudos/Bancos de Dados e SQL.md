# 📚 Bancos de Dados e SQL

> **Disciplina:** `Engenharia de Dados` | **Data:** 2026-10-03 | **Status:** `Revisar`

---

## 🎯 Ideia Central (Resumo em 3 Frases)
- Modelagem de dados relacionais e não-relacionais para persistência consistente.
- Domínio de consultas SQL avançadas (JOINs, agregações, índices e transações ACID).
- Otimização de planos de execução de queries.

---

## 🧠 Flashcards (Repetição Espaçada)
O que significa a sigla ACID em bancos relacionais?::Atomicidade, Consistência, Isolamento e Durabilidade.
Para que serve um índice de banco de dados?::Para acelerar operações de busca (SELECT) ao custo de maior uso de espaço e ligeira lentidão em INSERTs/UPDATEs.
