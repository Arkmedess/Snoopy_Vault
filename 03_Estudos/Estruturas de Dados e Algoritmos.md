## 🎯 Ideia Central (Resumo em 3 Frases)
- Estudo de como organizar e manipular dados eficientemente na memória.

## 🧠 Flashcards (Repetição Espaçada)
O que é complexidade Big-O?::É uma notação assintótica que descreve o comportamento limite de uma função de custo computacional conforme a entrada cresce.
Qual é a complexidade média de busca em uma Hash Table?::O(1) tempo constante médio.
